## Viewing and running

GitHub renders the notebooks directly. To run locally, install JupyterLab or open them with a compatible Jupyter notebook environment:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows PowerShell: .venv\Scripts\Activate.ps1
pip install jupyterlab ipython
jupyter lab
```

Some assignment cells may expect class-provided text/data files that are **not included in this repository**. Outputs already saved in notebooks are not evidence that a clean environment can reproduce every exercise.
